### ① アプリ化 ＝ PWA
- ネイティブではなく PWA。`ui/lask-home.html` をそのまま「ホーム画面に追加」で全画面起動。ストア審査ゼロで今日出せる。App Store は 1万人段階（企画書 §7 段階3）で

対応（実装済み・ブランチ `feat/app-pwa`）：

- **拾う操作**：チェック（✓ 終わった／戻す）／ボタン（違う・もういい・降ろす・今日は当てない ＝ 消す系、わかった・合ってる・最初の一手を作る…＝ 押した記録）／配分のつまみ（離した時の値）／タブ・詳細・夢の領域タップ（view）
- **状態の復元**：開いた瞬間に `/api/state` を当てて、消したもの・終わったもの・押したもの・つまみの位置を戻す。端末が変わっても同じ
- **秋好OS への吸収**：Lask の操作を 📦母艦（全入力の原本）に「秋好の入力」として1件ずつ転記（20秒ごと・未転記分だけ・view は転記しない＝Lask 内の履歴に留める）。項目：入力元 `Lask`／型 `記録`／発言者「秋好（Lask の操作）」／全文＝「2026-09-20 21:03 Lask 夢タブ「止まっている」で「南極」に「もういい」」／文脈＝操作の JSON／冪等キー `lask:op:<id>`／領域は 仕事→仕事・体→体・他→個人
- 転記に要るのは Railway Variables の `NOTION_TOKEN`（秋好OS と同じ integration で可。Lask 側は母艦に page を足す権限しか使わない）。未設定の間も ops は Lask の DB に溜まり、設定した瞬間から追いつく
